> question is written here rather than guessed at. Pascal escalates to the architect.

> [§3 Resolved](#3-resolved) with the answer recorded, so the reasoning survives. `Blocking?` means
> *blocking for the week named*, not blocking forever. Where an implementation had to proceed without
> an answer, the assumption made is stated in §2 so it can be reversed cheaply if the answer differs.
